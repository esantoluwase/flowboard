# FlowBoard — Project Management Workspace

A responsive, browser-based project and task management demo built with **HTML, CSS, Vanilla JavaScript and LocalStorage**.

## Run locally
1. Download and extract the ZIP.
2. Open `index.html` in a modern browser.
3. No build step, package installation, backend or API key is required.

## Deploy to GitHub Pages
1. Open your `flowboard` repository on GitHub.
2. Upload the four project files (`index.html`, `style.css`, `script.js`, `README.md`) to the repository root, replacing the existing versions when prompted.
3. Commit the changes to the `main` branch.
4. In **Settings → Pages**, confirm deployment from the `main` branch and `/ (root)`.
5. Wait for GitHub Pages to publish, then refresh https://esantoluwase.github.io/flowboard/.

## Features
- Overview dashboard and workspace statistics
- Project creation, editing and deletion
- Five-stage Kanban board: Backlog, To Do, In Progress, Review and Done
- Task creation, editing, deletion and drag-and-drop status changes
- Manual status selector as an alternative to drag-and-drop
- Task search, priority and assignee filters
- My Tasks, Team and Reports views
- CSV task export and JSON workspace backup
- Light/dark theme
- Responsive layout for desktop and mobile
- LocalStorage persistence

## Important scope notes
This is a frontend demonstration/MVP. Data is saved in the current browser only. It does **not** provide real user authentication, a hosted database, cross-device synchronization, real-time multi-user collaboration, email notifications or server-side security. Team members are sample profiles for demonstration.

## Files
- `index.html` — app structure and views
- `style.css` — layout, components, responsive and theme styles
- `script.js` — sample data, interactions, state and LocalStorage
- `README.md` — setup and deployment guide
